# NAI V5 단부루 태그 레퍼런스

NovelAI V5로 그림을 만들 때 쓰는 **단부루(Danbooru) 태그 45,420개**를 한글명·게시물 수·관련 태그와 함께 찾아보는 웹 페이지입니다. 설치할 것 없이 브라우저에서 바로 열립니다.

## 무엇을 할 수 있나요

- **검색** — 영어(`long hair`), 한글(`긴 머리`), 초성(`ㄱㅁ`) 모두 됩니다. 위키 설명까지 뒤지는 토글도 있습니다.
- **복사** — 태그를 누르면 NovelAI 입력 형태(밑줄 → 공백)로 클립보드에 복사됩니다. `+ 담기`로 여러 개를 모아 쉼표로 이어 한 번에 복사할 수도 있습니다. 담은 목록은 브라우저에 저장돼 다음에 열어도 남아 있습니다.
- **분류 필터** — 일반 / 캐릭터 / 작품 / 작가 / 메타 / NAI전용. 일반 태그에는 **14개 그룹 · 82개 세부 분류**가 붙어 있어 머리·의상·포즈 같은 갈래로 좁혀 볼 수 있습니다.
- **관련 태그** — 일반 태그를 펼치면 함께 쓰이는 태그가 **분류별로 묶여** 나옵니다. 연관도(코사인)순 ↔ 빈도순 토글, 흔한 태그 숨기기, 분류별 ↔ 전체 보기 토글을 지원합니다.
- **증감 확인** — V4.5(2025-05) 대비 게시물 수 증가율과 막대그래프. 주황 눈금이 V4.5 시점 위치입니다.
- **없어진 태그 안내** — `skirt_hold` 처럼 지금은 사라진 태그를 검색하면 안내와 대체 태그 후보를 보여줍니다.

모바일 화면(375px)에 맞춰 만들었습니다.

태그 이름과 게시물 수는 단부루 및 위 저장소들의 자료이고, 각 저장소의 라이선스를 따릅니다. 이 페이지의 코드는 개인적·비상업적 용도로 자유롭게 쓰셔도 됩니다.

## 콘텐츠 기준

미성년자를 성적으로 다루는 태그·작품·작가 **34개를 목록과 관련 태그 양쪽에서 제외**했습니다. `lolita_fashion` `gothic_lolita` 같은 패션 계열과 `child` `aged_down` `toddler` 등 연령 표현 태그는 그대로 두었습니다.

## 파일 구조

```
index.html             앱 전체 (코드만, 약 70KB)
data/tags.json.gz      태그 45,420개 — 이름·한글명·분류·게시물 수·설명·세부 분류
data/related.json.gz   관련 태그 — 18,297개 태그 × 코사인 상위 60개
.nojekyll              깃허브 페이지가 파일을 그대로 서빙하도록
README.md
```

`index.html`은 상대 경로로 `data/`를 읽습니다. 저장소 하위 경로(`https://아이디.github.io/저장소이름/`)에 올려도 그대로 동작합니다.

데이터는 gzip으로 압축돼 있고 브라우저의 `DecompressionStream`으로 풉니다. **Chrome/Edge 80+, Firefox 113+, Safari 16.4+** 에서 열리고, 그보다 오래된 브라우저에서는 안내 문구가 뜹니다.

## 깃허브 페이지에 올리기

1. 저장소를 만들고 이 폴더의 파일을 **구조 그대로** 올립니다 (`data/` 폴더 유지).
2. 저장소 **Settings → Pages → Source** 를 `Deploy from a branch`, 브랜치는 `main`, 폴더는 `/ (root)` 로 지정합니다.
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 에서 열립니다.

`.nojekyll` 파일이 있어야 합니다. 없으면 깃허브가 일부 파일을 걸러낼 수 있습니다.

## 로컬에서 열어 보기

`index.html`을 파일로 직접 열면(`file://`) 브라우저가 `data/` 읽기를 막습니다. 이 폴더에서 아래를 실행한 뒤 `http://localhost:8000` 으로 여세요.

```
python -m http.server
```

인터넷 없이 쓰실 거면 단일 파일 버전(`nai_v5_tag_reference.html`)을 쓰시면 됩니다. 데이터가 파일 안에 들어 있어 더블클릭만으로 열립니다.

## 데이터 갱신하기

1. `collect_cosine.py` 로 관련 태그를 다시 수집합니다 (VPN 필요, 전체 약 1시간).
   ```
   python collect_cosine.py            # 기본: 초당 5회, 태그당 200개
   python collect_cosine.py --rps 3    # 더 천천히
   ```
   끝나면 `related_tags_merged.jsonl.gz` 가 만들어집니다.
2. 태그 마스터 데이터(`nai_v5_danbooru_tags_v5.xlsx`)를 새 스냅샷으로 갱신합니다.
3. 빌드 스크립트로 `data/tags.json.gz` 와 `data/related.json.gz` 를 다시 만들어 이 폴더에 덮어씁니다.
4. 저장소에 올리면 끝입니다.

단부루 API는 읽기 요청이 **초당 10회**가 상한이고, 문서는 오래 도는 작업이라면 초당 1회 정도를 권합니다. 수집기 기본값은 초당 5회이고 429 응답을 받으면 스스로 느려집니다. 남의 서버이니 급하지 않으면 `--rps 3` 정도를 써 주세요.
